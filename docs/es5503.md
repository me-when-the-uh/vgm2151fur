# Ensoniq ES5503

The ES5503 is the Apple IIgs wavetable/sample chip. VGM 1.71 stores its clock
at header `0xCC`, its output-channel count (1-8) at `0xD4`, and register
writes as command `0xD5 pp aa dd`. Wave data arrives as data-block type
`0xE1`: a 32-bit RAM start address followed by bytes. The chip has 128 KB of
wave RAM and 32 oscillators.

## Register model

The register byte is split into an oscillator number (`reg & 0x1F`) and a
register class (`reg & 0xE0`):

- `0x00` frequency low, `0x20` frequency high
- `0x40` volume (0-255 linear)
- `0x80` wave-table pointer high byte (the pointer is 256-byte aligned)
- `0xA0` control: bit 0 halt, bits 1-2 mode, bit 3 IRQ, bits 4-7 output mask
- `0xC0` bank select (bit 6), wave size class (bits 3-5), resolution (bits 0-2)
- global `0xE1` sets the enabled-oscillator count:
  `((data >> 1) & 0x1F) + 1`

The chip reads one wave byte per output step. The output rate is

```
output_rate = (clock / 8) / (enabled_oscillators + 2)
```

and the frame rate of one oscillator is

```
rate = output_rate * freq / 2 ** (9 + resolution - size_class)
```

A wave body ends at the first `0x00` byte, where the chip halts the
oscillator; the declared size class only bounds the address window.

## Conversion

Furnace has no ES5503 platform, so each oscillator that actually plays
becomes one 1-channel Generic PCM DAC system. The systems follow MSM5232 and
precede the SCC/AY tone block.

- Wave RAM is assembled from the `0xE1` blocks. Each body is stored once per
  `(pointer, size class)` and shared by every oscillator that plays it.
- Unsigned `0x80`-centred wave bytes become signed 8-bit samples. The body
  stops at the chip's `0x00` terminator.
- The most common playback rate of a body is its C-4 reference rate; every
  hit then maps through `rate_to_note` into note/E5, exactly like the
  K054539/C140 paths. `DAC_RATE_COMPENSATION` keeps the stored clock in step
  with Furnace's DAC reference.
- Key-on and key-off writes become notes and note-offs.
- The control output mask becomes `08xy` panning: with the usual two output
  channels mask 0 is left and mask 1 right; a single-channel header centres
  everything.
- The volume register is written directly to the volume column. Every
  oscillator's PCM DAC system stays at 1.0; the module master carries the
  VGM's main-volume field (0.918 on the Apple IIgs sample rips), so the source
  gain is preserved without boosting any channel.
- Mode 0 (free-run) loops a body that has no `0x00` terminator. Mode 1
  (one-shot) is the common case. Sync/AM and swap modes are approximated as
  one-shot and reported.

## Limits

- One PCM DAC system per used oscillator is exact, but the `.fur` header holds
  only 32 chip slots. The ES5503-only sample packs use at most 28, so they fit;
  a mixed log near the limit should merge equivalent stereo pairs.
- The source's ES5503 output gain is not raised to match VGMPlay. Each PCM
  DAC system stays at 1.0 and the module master carries the VGM main-volume
  field, so the source's gain setting is kept without extra boost.
- Mid-note wave-table pointer/size changes are reported; only the key-on table
  is used. Mid-note volume and frequency writes are carried as volume steps
  and pitch ramps.
