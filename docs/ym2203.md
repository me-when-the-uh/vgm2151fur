# YM2203 (OPN) notes

The YM2203 is a three-channel FM chip with an AY-3-8910-compatible SSG and
two general-purpose I/O ports.  Furnace calls it `YM2203` (system id `0x8d`)
and exposes six channels: **FM 1-3** then **PSG 1-3**.  The SSG is part of
the same workstation, not a separate AY chip, so it uses the same Furnace
system and the PSG channels right after the FM ones.

## VGM stream

| What | Where |
| --- | --- |
| Clock | header `0x44`; bit 30 means a second YM2203 instance |
| FM writes | command `0x55`, register `>= 0x20` |
| SSG writes | command `0x55` (or `0xA5` for the second chip), register `0x00-0x0F` |
| Second chip FM/SSG | command `0xA5` |

`vgm.py` splits every write into `ym2203` (FM) and `ym2203_ssg` (SSG) so the
FM model never confuses the SSG register bank with FM operators.  The loader
accepts an out-of-spec `0xA5` on a single-chip log as chip 0 and warns, which
is how some old rips store the SSG port.

The clock is passed to Furnace as `customClock=<hz>` unless it is the
3,579,545 Hz default.  A dual log becomes two consecutive `0x8d` systems,
each with its own clock flag.

## Channel layout

One chip, six module channels:

```
0-2   FM 1-3
3-5   PSG 1-3
```

Two chips occupy twelve channels, chip 0 then chip 1, so FM 1-3 / PSG 1-3
of each block are always adjacent.  Sample chips and SCC/AY chips, when
present, start after the complete YM2203 block.

## FM notes and pitch

Furnace runs its YM2203 platform with the module's **linear pitch** mode
(the converter writes the linear-pitch compatibility default).  In that mode
a pattern note is `note << 7` engine pitch units, E5 adds `(value - 0x80)`
units of 1/128 semitone, and a pitch macro adds in the same units before the
platform converts the note to an f-num/block.  This is unlike the YM2151's
KC/KF model where E5 is a 1/64-semitone register unit.

The converter therefore:

1. snapshots the block/f-num registers at each `0x28` key-on;
2. chooses the equal-tempered note whose f-num is nearest in the same
   clock, and puts the remainder into E5 as 1/128-semitone units;
3. follows later f-num writes with a **pitch macro** on an instrument copy
   (`_bind_fm_pitch`).  The macro is a signed 16-bit sequence at one entry
   per module tick, so vibrato, ramps and slides survive inside the note.
   The first entry is zero; the note's E5 already holds the key-on pitch.

A note is created when a key-on mask adds an operator.  Key-off (`0x28`
with mask 0) creates a NOTE_OFF row except when a new key-on follows within
two samples (a retrigger must not cut the new note).  A key-on with only some
operators masked gives the unkeyed operators TL 0x7F so they stay silent.

Driver ticks that only touch timers (Iron Horse writes `0x27=0x39/0x3b`
every frame) are ignored.

### Octave convention and carrier MULT

The base note is the source channel's f-num/block, named with Furnace's
note convention (`furnace_note_name`: note 60 = C-0, so note 96 = C-3).
At 1.5 MHz a block-3 f-num 1646 is **C-3 / 130.81 Hz**.

A YM2203 patch can have a carrier with MULT=2 (Legendary Wings OPN 00 is
alg 5 with carrier op2 MULT=2), in which case the strongest/audible carrier
is an octave above the channel f-num.  The converter labels the pattern
note at that carrier octave (A#3 -> A#4 for OPN 00) and writes a constant
`-1536` (one octave, 1/128-semitone units) pitch macro on the instrument.
The macro cancels the relabel in Furnace's linear-pitch path, so the
source f-num, block, key scaling and envelopes are unchanged; the x4
module still exports exactly the VGM's f-num/block.  Carrier MULT=0 (0.5)
does the same downwards.  Patches whose carriers are MULT=1 (Legendary
Wings OPN 01, the C-3/C-2 bass) stay at the channel octave.

If you edit such an instrument, keep the constant pitch macro or remove
both it and the +12 note; removing only one changes the sounding pitch.
The tests `TestYm2203OctaveConvention` (f-num mapping) and
`test_carrier_mult_two_labels_note_an_octave_up` (the compensation) lock
this down.

### 3-slot mode

Register `0x27` bit 6/7 selects CSM / 3-slot operation.  A driver then
writes per-operator f-nums for channel 3 at `0xA8-0xAA` / `0xAC-0xAE`
(operators 2-4; operator 1 keeps `0xA2/0xA6`).  Furnace's six-voice YM2203
system has one note per channel, so the converter uses the first written
extra operator as the channel pitch.  The chord's other components are
lost, and the analysis reports how many such writes it saw.  CSM timer
key-ons that the chip generates internally are not synthesized; explicit
`0x28` key-ons are.

## FM instruments

The `.fur` instrument is type 1 (`INS_FM`, OPN), not the YM2151's OPM type.
Operators are stored in YM2203 register order (`0x30/0x34/0x38/0x3c`), which
is also Furnace's internal FM order.  The INS2 `FM` feature carries:

| Register | Feature field |
| --- | --- |
| `0x30` DT/MULT | `dt` / `mult` (Furnace's DT table mapping) |
| `0x40` TL | `tl` |
| `0x50` KS/AR | `rs` (bits 6-7) and `ar` |
| `0x60` AM/D1R | `am` and `dr` |
| `0x70` D2R | `d2r` / `sr` (5 bits) |
| `0x80` SL/RR | `sl` / `rr` |
| `0x90` SSG-EG | `ssgEnv` |
| `0xB0` FB/ALG | `fb` / `alg` |

There is no DT2 field on the YM2203 and the converter leaves it zero.
Carrier operators get KVS=2 so the pattern volume column scales the audible
operators; modulators keep KVS=0.  The instrument `block` field stays 0 so
the pattern note chooses the octave.

## SSG

The SSG is converted through the same AY-8910 model as a stand-alone AY chip
but with Furnace's YM2203 divider of **16** (a stand-alone AY uses 8).  The
register bank is the normal AY one: tone periods `0/1`, `2/3`, `4/5`, noise
`6`, mixer `7`, volumes `8-10`, envelope period `11/12`, shape `13`, I/O
`14/15`.  The resulting notes use `DIV_INS_AY` instruments and the ordinary
`20xx-2Fxx` PSG effects (channel mode, noise period, envelope).  The SSG
clock is the YM2203 clock.

Period writes faster than the module tick are handled by raising the tick
rate while keeping the row length, BPM and pattern grid (`_tone_pitch_tick_scale`).
This preserves Commando's fast SSG arpeggios without changing the song's
rows.  Periods below the representable/harmonic range (for example 0 used
as a gate-off by some drivers) are treated as silence, matching Furnace's
own AY gate.

## Verification

The two debug tools understand YM2203:

- `opn_pitch_stream` reads FM block/f-num or SSG tone period and maps a
  module channel to the right chip instance.  In 3-slot mode it follows the
  per-operator registers, so the comparison measures the sounding pitch,
  not the unused normal f-num.
- Runs are only compared while the source channel is keyed (and, for SSG,
  only while a representable tone is actually sounding), so register writes
  in a rest do not look like pitch errors.

The full `VGM_collection/YM2203` corpus (210 files, including 190 with a
YM2203 and dual-chip Psychic 5, Legendary Wings and Iron Horse packs) was
converted and exported through Furnace:
**zero divergent pitch for 206 files**.  The remaining four are short
artifacts, not systemic errors:

- Psychic 5 `08 Genzo's Theme`: 82 ms, worst 10.7 st.  The source uses a
  3-slot chord on FM channel 3; Furnace's six-voice system reproduces one
  operator of the chord (see above).
- Psychic 5 `04 Clear` and `14 Continue`: 0.65 s / 0.31 s of sub-row SSG
  chirps and slides, worst 5.0 st / 1.4 st.  These are fast pitch ornaments
  shorter than a pattern row that the shared AY long-note macro intentionally
  simplifies.
- Gunnail `19 Ending`: 51 ms, worst 43 st.  A short SSG effect transient
  that is gated off again before the next row.

The FM key-on pitch, the OPN instrument register state, the YM2203 clock
headers, dual systems, the SSG tone periods and the SSG instruments were
also checked individually against Furnace's VGM export in
`tests/test_vgm2151fur_ym2203.py`.
