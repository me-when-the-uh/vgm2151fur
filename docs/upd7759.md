# NEC uPD7759

The uPD7759 is a one-voice ADPCM speech chip.  VGM command `0xB6 aa dd`
writes one of four registers:

- `0` reset line
- `1` start line
- `2` port / FIFO data
- `3` ROM bank base (`dd << 17`)

Bit 30 of the header clock at `0x8C` marks a second chip, and bit 31 selects
slave mode.  The extra header (id `0x16`) can provide the second clock.

## Stand-alone mode

The `0x8A` data block carries a phrase ROM:

```
nn 5a a5 69 55          nn = last phrase number
<16-bit vectors>        phrase address = value * 2 + 1
```

A start rising edge while reset is high and the chip is idle plays the phrase
selected by the last port value.  The decoder follows MAME's state machine:
`00dddddd` is silence, `01ffffff` sends 256 nibbles, `10ffffff nnnnnnnn`
sends `n + 1` nibbles, `11---rrr` repeats the following block, and a `00`
after a valid block ends the phrase.  The clock divider gives a nibble rate of
`clock / (4 * (rate + 1))`.

## Slave mode

When bit 31 is set the chip has no phrase ROM.  The CPU streams command bytes
through the port.  The converter consumes the six-byte port handshake and
decodes the same command grammar with `decode_stream()`.

## Module representation

Furnace has no native uPD7759 platform, so each chip becomes a **Generic PCM
DAC** system with one column.  Every unique phrase is rendered to 16-bit PCM
at 44.1 kHz at MAME's level scale (`sample << 7`), stored as a module sample
and played through a 120-slot sample map.  Identical phrases share one body,
and each hit ends when its phrase ends.  The map keeps a speech-heavy rip
inside the instrument budget; each slot plays at C-4.

## Limits

- A phrase's internal rate changes are resampled into the single module body.
- The chip is one-voice per instance; overlapping start commands are ignored
  while the previous phrase is still busy.
- A ROM block that is not present in the VGM cannot be reconstructed.
