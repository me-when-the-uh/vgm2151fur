# Philips SAA1099

The SAA1099 is the six-voice stereo PSG used by the Creative Music System /
Game Blaster (two chips) and the SAM Coupe (one chip).  VGM carries it as
command `0xBD` and a clock at header offset `0xC8` (VGM 1.71+).  Bit 30 of the
clock marks the second chip; bit 7 of the `0xBD` register byte selects it.

## Registers

| Register | Meaning |
|---|---|
| `0x00`-`0x05` | amplitude: low nibble left, high nibble right |
| `0x08`-`0x0D` | frequency offset, 8 bits |
| `0x10`-`0x12` | octave, low/high nibble for a channel pair |
| `0x14` | tone enable, bits 0-5 |
| `0x15` | noise enable, bits 0-5 |
| `0x16` | noise generator: low 2 bits group 0 (channels 0-2), high 2 bits group 1 (channels 3-5) |
| `0x18`/`0x19` | envelope control for group 0/1 |
| `0x1C` | bit 0 output enable, bit 1 sync |

There is no key-on.  A voice is audible when its amplitude is nonzero, its
tone or noise bit is set and the chip is not muted.  A new note starts when an
inaudible voice becomes audible, when the amplitude jumps back up while the
gate stays open, or when noise is added to a sounding tone voice (a percussion
attack).  The collector batches every write at one sample first: a Furnace
export writes the volume and pan macros as separate amplitude writes on the
same tick, and only the final register value is heard.

## Pitch

The chip plays

```
clock * 2**octave / (512 * (511 - offset))
```

Furnace's six-voice no-timer system (`0x97`) uses the period pitch table with
`divider=2` and `maximum=0xffff`.  Its platform converts a table value `freq`
into

```
k = bit_length(freq) - 9        (0 when freq <= 511)
offset = 255 - (freq >> k)      (stored as a byte)
octave = 7 - k
```

so a source `(offset, octave)` is every table value in
`[(511-offset) << k, (511-offset+1) << k)` with `k = 7 - octave`.  The
collector hands the midpoint of that bucket to `furnace_period_note`, which
finds the note/E5 pair closest to it.  All 2048 register pairs round-trip.

Pitch writes inside one gate are kept on the note's pitch macro at the exact
tick rate.  SAA drivers use fast detunes as a pseudo-duty cycle; step-length
thinning would change the duty ratio, so those macros are not step-compressed.

## Amplitude, pan and volume

Furnace's platform writes the amplitude register as

```
applyPan(outVol, pan) = (outVol * (pan >> 4) / 15) | ((outVol * (pan & 15) / 15) << 4)
```

For a SAA note the writer therefore stores the raw left/right nibbles on the
**pan-left/pan-right** instrument macros (file codes 12/13), with the pattern
volume column at 15:

```
applyPan(15, (left << 4) | right) == the source amplitude byte
```

This is exact for hard pan, soft pan and a volume envelope at the same time.
The instrument prefix merge may share a shorter macro only when both pan
macros match left-to-right for the note duration.

## Noise

A chip has two noise generators, one per three-voice group.  A note's mode is
the `10xy` effect (`x` = noise, `y` = tone); the group's generator frequency is
`11xx` (0 high, 1 mid, 2 low, 3 channel-1/4 frequency).  Mode and noise
frequency changes inside a note are the instrument's wave/duty macros (file
codes 3 and 2); the row effects carry the opening state.

## Envelope

Registers `0x18`/`0x19` enable the two envelope generators.  With bit 5 clear
the envelope is clocked by the frequency of channel 2/5 (0-based 1/4) and
heard on channel 3/6 (0-based 2/5).  The raw control byte is the instrument's
ex1 macro (file code 5) on the output voice.

The source oscillator must keep running even when its own amplitude is zero,
or the envelope rate falls back to the reset frequency.  When an internal
envelope is enabled and the source voice has no audible note, the converter
emits a **silent source note** at volume 0 and splits it at every frequency
change.  The note is inaudible but its oscillator clocks the envelope
generator correctly.

## Clock

Furnace's `0x97` system has three presets: `clockSel=0` = 8 MHz,
`clockSel=1` = `COLOR_NTSC * 2`, `clockSel=2` = `COLOR_PAL * 8 / 5`.  Any
other clock is stored as `customClock`.  Two systems are named "Creative
Music System" by Furnace.

## Effects

| Effect | Meaning |
|---|---|
| `08xy` | pan left/right (used for a fixed balance when no pan macro is kept) |
| `10xy` | channel mode: `x` noise, `y` tone |
| `11xx` | noise generator frequency/source |
| `12xx` | envelope control byte |

## Limitations

- The envelope is modelled as the raw control macro plus the silent source
  note.  A driver that externally strobes the envelope faster than one tick is
  not reproduced; the Game Blaster examples use the internal clock.
- The unused registers (`0x06`, `0x07`, `0x0E`, `0x0F`, `0x13`, `0x17`,
  `0x1A`, `0x1B`, `0x1D`-`0x1F`) are ignored.
- A source that leaves a voice's pitch register at reset while another voice
  uses it is not synthesised beyond the note/E5 and pitch macro model.
