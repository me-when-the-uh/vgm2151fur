# Irem GA20

The GA20 is Irem's four-voice 8-bit sample player (M92/M107 boards). VGM uses
command `0xBF` for a register write, header `0xE0` for the clock (VGM 1.71+)
and data block `0x93` for the sample ROM.

## Conversion

- Furnace system `0xC7`, four mono columns, instrument type `46`.
- Registers per voice: start `0x00/0x01`, end `0x02/0x03`, frequency `0x04`,
  volume `0x05`, control `0x06`. Bit 1 of control is key-on; clearing it is
  key-off. Start/end are 20-bit addresses with the low nibble zero.
- The chip stops when the fetched ROM byte is zero. The end register is not
  used during playback, so the collector extracts from start to the first
  `0x00` byte and does not truncate at the end register.
- ROM bytes are unsigned with `0x80` as silence. The SMP2 body is signed, so
  the collector subtracts `0x80`; Furnace's GA20 uploader XORs it back.
- Playback rate is `clock / (4 * (0x100 - frequency))`.
- Furnace's GA20 pitch table ignores each sample's center rate, so every body
  stores the table's fixed C-4 reference (`clock / 428` for the standard
  clock). The source frequency register gives the exact period Furnace must
  load (`0x100 - frequency`); the converter searches the platform's 13-entry
  period table and emits the closest note/E5 pair. This matters because the
  GA20 table is coarser than equal temperament, especially at high pitches.
- Volume writes are kept as the pattern volume and mid-note volume points.
  Mid-note frequency writes become pitch points where the writer can place
  them.

## Limits

- A source body longer than Furnace's 1 MB GA20 sample memory is truncated.
- The GA20 has no loops and no panning.
- An old VGM 1.51 file can contain a GA20 ROM block without a GA20 clock or
  `0xBF` writes; the converter then converts only its other chips.
