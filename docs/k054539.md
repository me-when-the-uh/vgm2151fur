# Konami K054539

VGM stores the K054539 clock at header `0xA0`; command `0xD3` writes a 16-bit
big-endian offset (bit 15 selects a second chip) followed by one data byte.
Data block `0x8C` is the sample ROM. The flag byte at `0x95` is read; the
converter always models libvgm's forced update-at-key-on behaviour.

## Conversion

Furnace has no K054539 platform, so each of the eight hardware voices becomes
one 1-channel Generic PCM DAC system (`0xC0`). A chip therefore occupies
eight columns, and a dual-chip log sixteen.

- Registers per channel: pitch delta `0x00-0x02`, attenuation `0x03`, reverb
  send `0x04`, pan `0x05`, loop address `0x08-0x0A`, start address
  `0x0C-0x0E`.
- `0x214`/`0x215` are the key-on/key-off masks. `0x22F` bit 0 enables PCM and
  bit 7 disables key-on/key-off updates. Start writes are latched while PCM
  is enabled and copied at key-on.
- Sample formats:
  - `0x0`: signed 8-bit, marker `0x80`
  - `0x4`: signed 16-bit little-endian, marker `0x00 0x80`
  - `0x8`: 4-bit DPCM, marker `0x88`; decoded to 16-bit linear
- The loop flag is byte `base2[1]` bit 0. A looping body plays from the start
  address to the marker and loops back to the loop address. A non-looping
  body ends at the marker.
- Playback rate is `(clock / 384) * delta / 65536`; sample C-4 rates use the
  most common played delta, and note value plus `E5` carries each hit's pitch.
  Mid-note delta writes become pattern sweeps.
- Volume is the chip's attenuation curve
  `10^(-36 * vol / 64 / 20)`, written to the PCM DAC volume column. Panning
  uses the 15-position square-root table as `08xy`.
- Key-off emits a note-off. A one-shot body stops at its marker; a looping
  body stops at the source key-off.
- A key-on closed by a key-off on the same VGM sample produces no audio,
  because both writes take effect before the next hardware tick. Such
  zero-length hits are dropped so a reset mask pair at the start of a log
  does not create silent or low-pitched sample instruments.

## Mix level

The decoded PCM body already carries the K054539 voice level. Every
one-voice Generic PCM DAC system stays at **1.0**, and the song master stays
at 1.0 as well. Scaling each system to 0.25 made an eight-voice chip four
times too quiet.

## Limits

- Reverb send (`0x04`) is not representable on Generic PCM DAC. A nonzero
  send produces one warning and the dry signal is converted.
- A 4-bit DPCM looping body is decoded once to absolute 16-bit values. The
  hardware accumulator can drift across loop iterations when the loop's net
  delta is nonzero; the module cannot reproduce that drift.
- Reverse playback is decoded best-effort from the forward marker scan.
- A missing start/loop marker is capped and warned.
- Channel identity is preserved: source voice *n* is the *n*-th PCM DAC
  system, not a sample-map slot.
