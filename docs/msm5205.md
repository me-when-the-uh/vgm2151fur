# OKI MSM5205

VGM stores the MSM5205 clock at header `0xF0` (VGM 1.72+); command `0x32`
writes one ADPCM register/data nibble. There is no sample ROM block: the CPU
streams 3/4-bit ADPCM codes to the chip.

## Conversion

Furnace has no MSM5205 platform, so each chip becomes one Generic PCM DAC
system (`0xC0`) carrying a 16-bit PCM body.

The collector mirrors libvgm's MSM5205 state:

- reset (`0x32` register 0), data FIFO (register 1), slave VCLK (register 2),
  prescaler (register 4) and bitwidth (register 5)
- the same 49-step OKI difference table and step-index shifts
- output rate `clock / prescaler`, where the S1/S2 pair selects 96, 64, 48
  or slave mode

The stream is rendered on the VGM 44.1 kHz timeline, then split exactly like
the YM2612 DAC and 32X PWM paths:

- attacks are detected from rises out of the idle band;
- long rests split hits and are trimmed;
- identical bodies are shared;
- `--lossy-sample-clustering` optionally folds similar short bodies into a
  smaller bank (off by default).

Each retained body becomes one 120-slot sample-map instrument. A note at that
body's start time plays it at C-4.

## Mix level

Generic PCM DAC output is unity in Furnace. The module uses VGMPlay's MSM5205
chip volume (`0x100`) as the per-chip level and keeps the song master at 1.0.

## Limits

- The decoded PCM is the reference decoder's output; Furnace does not emulate
  the MSM5205 DAC/filter.
- A chip whose stream exceeds Furnace's sample or instrument limits is split
  at resets/attacks and reported.
- Slave mode relies on the logged VCLK writes; unusual drivers may not render
  with the same latency as the original chip.
