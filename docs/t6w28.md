# T6W28 / dual SN76489

The Toshiba T6W28 is the Neo Geo Pocket Color's stereo PSG.  It is register
compatible with the TI SN76489 and appears in VGM as two SN76489 streams:

| field | meaning |
|-------|---------|
| header `0x0C` bit 30 | a second SN76489 instance |
| header `0x0C` bit 31 | T6W28 mode (when bit 30 is also set) |
| command `0x50` | first SN76489 stream (T6W28 left half) |
| command `0x30` | second SN76489 stream (T6W28 right half) |
| command `0x4F` / `0x3F` | Game Gear stereo mask, first / second chip |

A log can carry either a dual pair of ordinary SN76489s or one T6W28, never
both.  The two forms are told apart by bits 30 and 31.

## Ordinary dual SN76489

Each stream keeps its own latch, periods, noise mode and 4-bit attenuation.
The converter emits two `0x03` (SMS) systems, four channels each.  A Game Gear
stereo mask on `0x4F` or `0x3F` applies to its own chip.

## T6W28

The two halves are one chip:

* Left (`0x50`) writes tone periods and the left attenuation.
* Right (`0x30`) writes the right attenuation.  Its channel-2 tone register is
  the extra noise period; its channel-3 register is the noise select
  (bits 0-1) and white-noise flag (bit 2).
* A tone sounds while either attenuation is below 15.  The source levels are
  `L = 15 - attL` and `R = 15 - attR`.

Furnace's T6W28 platform (`0xBF`) has independent `panL`/`panR` and computes

```
register attenuation left  = 15 - clamp(outVol + panL - 15, 0, 15)
register attenuation right = 15 - clamp(outVol + panR - 15, 0, 15)
```

The converter therefore stores the louder side in the volume column and the
difference in an `08xy` split:

```
vol  = 15 - min(attL, attR)
panL = 15 - (attL - min(attL, attR))
panR = 15 - (attR - min(attL, attR))
```

Mid-note attenuation changes become volume/pan steps.  Noise select 0-2 uses
the fixed periods `0x100`, `0x200` and `0x400`; select 3 uses the right half's
extra period.  `20xx` carries the white-noise flag.  Tone periods use Furnace's
divider 16, noise periods divider 15, at the T6W28 clock (normally 3072000 Hz).
