# Konami K053260

Four-voice PCM/KADPCM chip. VGM command `0xBA aa dd`, clock at header `0xAC`
(VGM 1.61+, extra-header id `0x1D`), ROM data block `0x8E`. Bit 7 of `aa`
selects the second instance. Both instances share the header clock. Furnace
plays it as system `0xCC` with four channels and accepts sample depths 8 and
7 (KADPCM).

## Registers

Each voice has eight registers at `0x08 + voice * 8`:

| Offset | Field |
| --- | --- |
| +0, +1 | pitch, 12-bit (low, then high nibble) |
| +2, +3 | length, 16-bit |
| +4, +5, +6 | start, 21-bit |
| +7 | volume, 7-bit |

`0x28` keys voices on and off in bits 0-3 and sets reverse in bits 4-7.
`0x2A` holds the loop flags in bits 0-3 and KADPCM in bits 4-7. `0x2C` and
`0x2D` carry three-bit pan for two voices each. `0x2F` bit 1 enables output.

## Playback

The source rate is

```
clock / (4096 - (pitch & 0xFFF)) steps/s
```

A PCM step plays one byte. An ADPCM step plays one nibble from the byte
fetched every two steps, low nibble first. Key-on pre-increments the address.
The byte at `start` is never played. A loop resets the address to `start`
and replays `length` bytes again. PCM therefore lasts `length` frames and
KADPCM lasts `2 * length` frames. No separate loop point exists.

KADPCM is the 16-entry delta table:

```
0, 1, 2, 4, 8, 16, 32, 64, -128, -64, -32, -16, -8, -4, -2, -1
```

The accumulator is signed 8-bit and wraps. The pan multipliers are
`(0,0) (127,0) (116,52) (104,73) (90,90) (73,104) (52,116) (0,127)`;
pan 0 silences the voice.

## Conversion

One sample body per distinct `(chip, start, length, KADPCM, reverse, loop)`
key. PCM bodies are signed bytes from `start + 1`; KADPCM bodies are the raw
nibble bytes. A PCM one-shot loses its trailing silent bytes. A loop and every
KADPCM body keep the programmed length: the silence is part of the loop
cycle, and a zero KADPCM delta holds the accumulator at its last value.
Reverse playback stores the descending bytes forward, with nibbles swapped
for KADPCM.

A looping hit is written with sample loop `0..frames`. The Furnace platform
writes the key-on length and the loop bit, and the chip loops the whole body.

The note is chosen by inverting Furnace's period table with
`divider = 16 * centerRate / 8372`, which makes note 108 play the sample at
its stored C-4 rate. Mid-note pitch writes become `01xx`/`02xx` ramps.
Volume register writes drive the volume column; pan writes drive effect
`08xy`. A key-on pan of 0 cannot be expressed by `08xy`, which the platform
maps to center. That note starts at volume 0 with no pan effect and is raised
when the pan moves.

The Furnace core shifts the voice product by 7 bits where MAME shifts by 6.
The desired gain is 2.0. The writer raises the master to 2.0, stores the
K053260 at 1.0 and scales the other chips down. The chip float is
master-relative, and the player multiplies it by the master once.

## Limits

- A loop always covers the whole sample.
- Mid-note loop, KADPCM and direction changes use the key-on value. The
  converter warns when they occur.
- Start and length writes while a looping voice runs use the key-on values.
- A 4 MB VGM region is addressed through the chip's 21-bit bus. Bytes above
  2 MB alias to the low addresses.
- Triggers that point outside the dumped ROM blocks are silent. The converter
  counts them in a warning.
