# OKI MSM5232

The MSM5232 is an eight-voice square-wave/additive tone generator with two
four-channel envelope groups. VGM stores its clock at header `0xF4` (VGM
1.72+) and uses command `0x43` for register writes. Older libvgm builds used
`0x2D`; the converter accepts both.

## Conversion

- Furnace system `0xBC`, eight columns, instrument type `43`.
- Registers `0x00-0x07` are per-voice pitch/gate. Bit 7 is key-on; clearing it
  is key-off. Values `0xD8-0xFF` select noise.
- The source pitch byte maps directly to note `72+pitch`, because Furnace's
  MSM5232 platform writes `0x80 | (note - 72)` to the pitch register. Valid
  source pitches stop at `0x57`, so the note stays inside Furnace's range.
- `0x08/0x09` are group attack and `0x0A/0x0B` group decay; they become
  `12xx` and `13xx` effects.
- `0x0C/0x0D` are group control (output enables and sustain); they become
  `10xy` effects.
- Noise key-ons emit `11xx 01`, and tone key-ons clear it with `11xx 00`.
- Key-off writes become note-offs.
- `0x1E/0x1F` (TA7630 external volume for the two groups) is mapped to the
  four channel volume columns; the same dB table libvgm uses is reduced to
  Furnace's 0-127 channel level. Mid-note changes become standalone volume
  column events.
- The module writes `customClock` when the source clock is not the Furnace
  default (2,119,040 Hz).

## Limits

- The source has no per-channel volume register; the channel volume is left
  at maximum and the envelope/group effects shape the output.
- External capacitor and group-envelope flags use Furnace's defaults unless a
  later source-specific profile is supplied.
- Noise pitch is ignored by the chip; the module uses a fixed note for noise.
