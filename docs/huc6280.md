# HuC6280 (PC Engine / TurboGrafx-16)

The HuC6280 PSG is a six-voice wavetable chip. It converts to Furnace's
`DIV_SYSTEM_PCE` (`0x05`, six channels). VGM writes arrive on command `0xB9`
as a register/value pair; the register file starts with a channel-select latch
at `0x00` followed by per-channel writes.

| reg | meaning |
| --- | --- |
| `0x00` | channel select (bits 0-2) |
| `0x01` | global balance (left/right nibbles) |
| `0x02` | frequency low byte |
| `0x03` | frequency high nibble (12-bit period) |
| `0x04` | control: bit 7 enable, bit 6 direct-D/A, bits 0-4 volume (0-31) |
| `0x05` | channel balance (left/right nibbles) |
| `0x06` | waveform data (5-bit) / direct-D/A sample |
| `0x07` | noise (bit 7 enable on voices 4/5, bits 0-4 period) |
| `0x08`/`0x09` | LFO frequency/control |

The clock lives at VGM header `0xA4` (VGM 1.61+); it is the PSG clock
(`3579545` on NTSC hardware). Command bit 7 of the register selects a second
chip instance.

## Pitch

A voice sounds at `clock / (32 * period)`. Furnace's PCE platform builds its
pitch table from the doubled PSG clock with a divider of 64 and writes the
table value straight into the period register, so the analyzer labels notes
with the PSG clock and a divider of 32 and `period_offset=0`.

## Wavetables and instruments

The waveform is 32 five-bit samples written through `0x06`. The write index
resets on a 1->0 direct-D/A transition and advances on each disabled write
(`pce_psg.cpp`), so a driver's full 32-byte load is captured exactly. Each
distinct image becomes one `DIV_INS_PCE` instrument (deduplicated across
voices and notes), and notes that share a wave share the instrument.

The PCE instrument stores its wavetable through Furnace's wave synth
(`ws.wave1`): there is no separate wave field, so the converted instruments
have "Enable synthesizer" checked with effect `none` and speed `0` (a static
wavetable, the same configuration the SCC converter uses). Disabling the
synth makes the platform fall back to whichever wave the channel last loaded
(usually wave 0), so it is required for correctness.

Rapid mid-note waveform rewrites become the instrument's wave macro
(`std.wave`). A gate-to-gate interval is one note; mid-note pitch steps become
either new notes (a step of at least 0.75 semitone held for a frame) or the
instrument's pitch macro (`std.pitch`).

## Volume and panning

The chip's per-side level is `0x1F - min(0x1F, gbal + bal + al)`, where
`al = 0x1F - control_volume` and each balance nibble becomes
`0x1F - BALANCE_SCALE[nibble]`. Drivers use the control volume **or** the
balance register (often the balance alone, with the control volume pinned at
31) for the envelope, so the converter combines them:

- the louder side's level goes on the pattern **volume column** (0-31), so the
  envelope is visible where a tracker user looks for it;
- the left/right ratio goes on the **`08xy`** pan effect.

Feeding that back through the same chip model reproduces the original two
levels exactly: the louder side uses balance nibble 15 with
`al = 0x1F - peak`, and the quieter side picks the nibble whose attenuation
closes the gap. Mid-note control-volume and balance changes stay as row steps
(not a volume macro), so a fast fade is still captured.

## Noise (voices 4 and 5)

Voices 4 and 5 can enable periodic noise (`0x07` bit 7). The note is
`60 + (noise & 0x1F)` and the platform's noise (duty) macro carries the mode.
The noise period often sweeps while bit 7 is set; that becomes the note's
pitch macro (the platform adds `std.pitch` directly to the noise register).

A gate can switch between noise and the loaded waveform several times (LOX1
Wave 5 turns noise off for a tone passage and back on). The converter splits
at every transition:

- a noise segment is `60 + (noise & 0x1F)` with its register changes as the
  pitch macro;
- a tone segment is the waveform at the frequency register, with its period
  changes as the pitch macro.

Each segment's instrument states its mode (`[1]` for noise, `[0]` for tone),
so the switch happens on the note's first tick. The note boundary is placed
with `EDxx`, which gives tick resolution; an `11xx` row effect would only
have row resolution. Splitting at the transition also keeps each segment's
pitch macro from being thinned (a single macro over a 35 s gate is capped at
255 steps, roughly 140 ms each).

The whole gate keeps the balance envelope, or every hit would play at one
flat level.

## Direct-D/A PCM

Register `0x06` in direct-D/A mode (control bit 6) is a 5-bit sample register.
The DAC stream control commands (`0x90-0x95`) feed 8-bit DDA levels from a
type-`0x05` data block (`0x93` plays an offset/length, `0x95` a whole block).
Each play becomes an 8-bit `SMP2` body played at note 108 (C-4) at its stored
byte rate, with a `DIV_INS_AMIGA` sample instrument.

The body byte is `((v << 3) + 0x80) & 0xFF` for a DDA level `v`. Furnace turns
a sample byte back into the register with `(int8_t)(b ^ 0x80) >> 3 & 0x1f`,
so this choice reproduces the original 0-31 register stream exactly.

The byte rate (`0x92`) is the playback pitch and some drivers retune it
constantly (23442 writes on the faceball rip, 150 distinct rates). A body is
deduplicated by its data, so one sample is kept and each play is pitched by
note + E5: `2**((note-108)/12)` scales the body's centre rate, and the E5
fine tune carries the remainder at 1/128 semitone. The body is 8-bit (each
byte is a 0-31 DDA level; the stream step size and libvgm's C6280 command
size are both one byte), not 16-bit.

## Module layout

A log with no FM write omits the analyzer's legacy YM2151 placeholder: the
module opens with the PCE system alone (six columns). A Famicom AY is still
handled separately as a Sunsoft 5B.

## Limits

- The global balance (`0x01`) is read but not mapped (Furnace has no master
  balance per chip).
- The LFO (`0x08`/`0x09`) is not converted.
- Sub-frame gates (shorter than 100 samples) are dropped and counted.
- The noise tail split assumes the first `0x07` bit-7-clear write ends the
  noise part; a driver that re-enables noise later in the same gate keeps the
  tail as tone.
